# Sistema Solar

Vista web ligera del Sistema Solar. Consulta posiciones heliocéntricas medias para una fecha elegida mediante el servicio VOS⁴O del IMCCE.

## Uso local

Abre `index.html` en un navegador moderno. No requiere dependencias ni compilación. Hace una consulta inicial para la fecha local actual; para cambiar de fecha, selecciona una nueva y pulsa **Actualizar**.

## Publicación en GitHub Pages

Este sitio es estático. Para publicarlo, crea un repositorio en GitHub, sube estos archivos y en **Settings → Pages** elige desplegar desde la rama `main`, carpeta `/ (root)`. GitHub Pages servirá `index.html` como página inicial.

## Datos

Las posiciones proceden de [VOS⁴O · IMCCE](https://vos4o.imcce.fr/). El diagrama es esquemático y comprime los tamaños para facilitar su comparación.
