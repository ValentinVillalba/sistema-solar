# Sistema Solar

Vista web ligera del Sistema Solar. Consulta posiciones heliocéntricas medias para una fecha elegida mediante el servicio VOS⁴O del IMCCE.

## Datos

Las posiciones proceden de [VOS⁴O · IMCCE](https://vos4o.imcce.fr/). El diagrama es esquemático y comprime los tamaños para facilitar su comparación.
